⚙️ वन-टाइम सेटअप (१० मिनिटं)

हे सिस्टीम खरंच काम करण्यासाठी गुगलच्या फ्री सेवांची ३ किल्ली ही फाइलमध्ये टाकली पाहिजेत. एकदा केलं की कायमचं झालं.

⚠️ महत्त्वाचं: ही फाइल थेट डबल-क्लिक करून उघडली तर लॉगिन/लोकेशन चालणार नाहीत. खालील होस्टिंग पायरी आधी पूर्ण करा — लोकेशनसाठी HTTPS (https://...) लागतो.

पायरी १ — Firebase खाते (सर्व्हरचं काम करतं)

  1. console.firebase.google.com वर तुमच्या गुगल खात्याने जा → Add project → नाव द्या (उदा. tracknet) → Create.
  2. डावीकडे Build → Realtime Database → Create Database → Location: Singapore/US (काहीही) → Start in test mode → Enable.
  3. Database च्या Rules टॅबमध्ये खालचं रुल्स पेस्ट करून Publish दाबा (यामुळे लिंक पाठवलेले लोक फक्त लोकेशन लिहू शकतात, वाचू शकत नाहीत; वाचण्याचा अधिकार फक्त तुमच्या लॉगिनला):
{
  "rules": {
    "sessions": {
      ".read": "auth != null && auth.token.firebase.sign_in_provider == 'password'",
      "$token": { ".write": "auth != null" }
    }
  }
}
  1. Build → Authentication → Get started → Anonymous चालू करा (Save) → परत या → Email/Password सुद्धा चालू करा (Save).
  2. Project Settings (गिअर आयकॉन) → Your apps → Web (</>) → नाव द्या → Register → तिथे दिसणारा firebaseConfig मधली apiKey, authDomain, databaseURL, projectId, appId ही मूल्यं खालील फाइलमध्ये टाकायची आहेत.

पायरी २ — Google Maps की (रिअल गुगल मॅप)

  1. console.cloud.google.com → वर तोच Firebase प्रोजेक्ट निवडा.
  2. APIs & Services → Library → "Maps JavaScript API" शोधा → Enable.
  3. APIs & Services → Credentials → Create Credentials → API key → की कॉपी करा. (फ्री कोटा दरमहा पुरेसा असतो; बिलिंग जोडावी लागते पण फ्री लिमिटपर्यंत बिल येत नाही.)

पायरी ३ — किल्ली फाइलमध्ये टाका

ही फाइल टेक्स्ट एडिटरमध्ये उघडा (Notepad/VS Code). सुरुवातीला हे दोन भाग दिसतील — तिथेच किल्ली टाका:

const FIREBASE_CONFIG = { apiKey:"…", authDomain:"…", databaseURL:"…", projectId:"…", appId:"…" };
const GM_KEY = "…";   // ← Google Maps की

पायरी ४ — होस्टिंग (फ्री, लिंक पाठवण्यासाठी आवश्यक)

  1. या फाइलेला index.html असं नाव द्या.
  2. app.netlify.com/drop उघडा → फाइल तिथे ड्रॅग करा → ३० सेकंदात https लिंक मिळेल (उदा. https://xyz.netlify.app).
  3. Firebase Console → Authentication → Settings → Authorized domains → Add domain → तो netlify डोमेन जोडा. (वरचं!) झालं — सिस्टीम लाईव्ह!
